# 草莓种植最佳实践

以下数据仅供参考，用于与实时传感器数据进行对比分析。

## 环境参数标准

### 温度 (Temperature)

- **最佳范围**: 
  - 白天: 20-25°C
  - 夜间: 10-15°C
- **开花期**: 15-20°C
- **成熟期**: 18-22°C

**调控建议**:
- `>30°C`: 需开启风扇通风降温
- `<10°C`: 需关闭风扇，采取保温措施

### 湿度 (Humidity)

- **最佳范围**: 60-80%

**调控建议**:
- `>85%`: 易滋生病害，必须开启风扇通风
- `<50%`: 植株易失水，需开启灌溉系统或增湿

### CO₂ 浓度

- **最佳范围**: 800-1200 ppm
- `<400 ppm`: 建议关闭风扇，减少流失

### 光照

- **最佳范围**: 30000-50000 lux
- `<20000 lux`: 需开启补光灯补光
- **补光时长**: 每天 12-14 小时

## 光谱分析 (Spectral Analysis)

### 关键波段

- **蓝光 (445nm)**: 抑制由于光照不足引起的植株徒长
- **红光 (680nm)**: 高光合效率关键波段，促进花粉萌发
- **近红外 (760nm)**: 植物组织反射峰，反映生物量

### NDVI 健康指数

- **计算公式**: (760nm - 680nm) / (760nm + 680nm)
- **正常范围**: 0.6-0.8 (健康植株)
- **异常情况**: <0.5 或 >0.9 预警受灾或养分缺乏风险

### 光谱数据获取最佳实践

**重要提示**：为了提高响应速度，请遵循以下原则：

1. **优先使用统计信息**：
   - 使用 `get_all_spectrum()` 获取光谱数据摘要（包含统计信息和样本通道）
   - 这比获取所有18个通道的详细数据快得多

2. **按需查询具体通道**：
   - 只有在需要特定通道的精确值时，才使用 `get_channel(name)`
   - 例如：计算NDVI时才查询 channel1(680nm) 和 channel2(760nm)

3. **避免重复查询**：
   - 一次对话中不要多次调用相同的光谱工具
   - 将获取的数据保存在上下文中重复使用

4. **简洁回复**：
   - 不要在回复中列出所有18个通道的数值
   - 只报告关键指标（如NDVI、异常通道等）

## 调控配色建议 (RGB LED Schemes)

### 生长期 (Vegetative)
蓝光为主，促进叶片生长
```json
{ "r": 50, "g": 100, "b": 255 }
```

### 花果期 (Fruit & Flower)
红光为主，促进开花结果
```json
{ "r": 255, "g": 100, "b": 50 }
```

### 平衡模式 (Balanced)
红蓝平衡，适合全生长周期
```json
{ "r": 200, "g": 50, "b": 150 }
```

## 生长阶段管理

### 1. 苗期 (Seedling Stage)
- 温度: 18-22°C
- 湿度: 70-80%
- 光照: 中等强度，蓝光为主

### 2. 营养生长期 (Vegetative Growth)
- 温度: 20-25°C
- 湿度: 65-75%
- 光照: 强光，蓝光为主

### 3. 开花期 (Flowering)
- 温度: 15-20°C
- 湿度: 60-70%
- 光照: 强光，红光增加

### 4. 结果期 (Fruiting)
- 温度: 18-22°C
- 湿度: 60-70%
- 光照: 强光，红光为主

## 使用指南

当用户询问环境参数、调控建议或植株健康状况时：

1. **对比分析**: 将当前传感器数据与上述标准对比
2. **识别差距**: 指出哪些参数偏离最佳范围
3. **提供建议**: 基于差距给出具体的调控措施
4. **考虑季节**: 结合当前季节和生长阶段调整建议
