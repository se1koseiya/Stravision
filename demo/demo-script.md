# 竞赛演示脚本

## 🎤 演示流程（总时长：5-8 分钟）

### 第一部分：需求介绍（1 分钟）

**台词**：
> "各位评委老师好！我是 Agent 开发工程师。在智慧农业大棚种植场景中，农场主需要实时了解大棚环境状况并获得专业建议。但传统 AI 助手无法获取实时传感器数据，导致建议与实际环境脱节。"
>
> "我们的目标是：让 AI 助手能够主动感知大棚环境数据，基于真实数据提供精准诊断和建议。"

**操作**：打开 `AGENT-DEVELOPER-WORKFLOW.md` 文件

---

### 第二部分：技术架构（1.5 分钟）

**台词**：
> "我们的解决方案是在 Skill 工程中注入数据提示词。大家可以看到这个技术架构图："
>
> "用户请求经过后端中间件时，中间件会自动获取实时设备数据和天气信息，然后注入到 AI 的系统提示词中，最后 AI 基于这些真实数据生成智能回复。"
>
> "关键设计有三点：
> 1. 数据注入发生在 AI 推理之前
> 2. 每次用户询问都会刷新最新数据
> 3. AI 被动接收数据，保证信息真实性"

**操作**：指向架构图，逐条解释关键设计

---

### 第三部分：现场编码演示（3-4 分钟）

#### 步骤 1：基础版本（30 秒）

**台词**：
> "现在我来演示现场编写提示词的过程。首先是基础版本..."

**操作**：打开 `demo/prompt-skill.ts`，指向版本 1

```typescript
export const BASIC_PROMPT = `
你是一个智慧农业助手的 AI。
请回答用户关于大棚种植的问题。
`;
```

**效果**：AI 只能给出通用建议，无法分析具体数据

---

#### 步骤 2：数据注入版本（1 分钟）

**台词**：
> "接下来，我们在提示词中注入实时设备数据。这些数据来自后端中间件，每次用户询问时都会自动更新。"

**操作**：
1. 打开 `demo/data-injection.json`
2. 展示设备数据结构
3. 切换到版本 2 的提示词

```typescript
export const DATA_ENHANCED_PROMPT = `
你是一个智慧农业助手的 AI。

## 当前设备数据（实时注入）
- 室内温度：32.5°C
- 室内湿度：55%
- 光照强度：12000 lux
...
`;
```

**效果**：AI 可以基于真实数据进行分析

---

#### 步骤 3：诊断逻辑版本（1 分钟）

**台词**：
> "有了数据还不够，我们还需要让 AI 具备农业专家的诊断能力。我在提示词中添加了草莓种植的最佳环境参数和诊断流程。"

**操作**：切换到版本 3 的提示词

```typescript
## 草莓种植最佳环境参数
- 温度：18-28°C（白天）
- 湿度：60-75%
- 光照：15000-30000 lux
...

## 诊断流程
1. 对比当前数据与最佳参数
2. 识别异常的环境因子
3. 按优先级排序问题
4. 提供具体的调节建议
```

**效果**：AI 能够识别问题并给出专业建议

---

#### 步骤 4：完整 Agent 版本（1.5 分钟）

**台词**：
> "最后，我们让 AI 升级为真正的智能体 (Agent)，具备任务规划和工具调用能力。"

**操作**：切换到版本 4 的提示词

```typescript
## 任务规划能力
<TASK_LIST>
{
  "title": "环境优化计划",
  "tasks": [
    {
      "id": "1",
      "title": "开启风扇降温",
      "status": "in_progress",
      "desc": "当前 32.5°C，目标降至 28°C 以下"
    }
  ]
}
</TASK_LIST>

## 工具调用能力
{
  "action": "toggle_relay",
  "device": 6,
  "value": 1
}
```

**效果**：AI 可以生成任务清单并直接调用设备 API

---

### 第四部分：效果演示（1.5 分钟）

**台词**：
> "现在让我们看看最终效果。我询问 AI 助手：'当前的大棚环境怎么样？'"

**操作**：
1. 打开 AI 助手界面
2. 发送问题："当前的大棚环境怎么样？"
3. 展示 AI 的回复（包含数据表格、问题诊断、任务清单、控制指令）

**预期效果**：
- 📊 数据表格展示
- 🔍 识别 4 个环境异常
- 💡 生成 4 步优化计划
- 🤖 直接调用设备 API

---

### 第五部分：总结（1 分钟）

**台词**：
> "通过数据注入技术，我们实现了从传统 AI 助手到智能体 Agent 的升级："

**操作**：打开 `AGENT-DEVELOPER-WORKFLOW.md` 的项目价值对比表

| 维度 | 传统 AI 助手 | 我们的智能体 |
|------|-------------|-------------|
| 数据感知 | ❌ | ✅ |
| 决策能力 | ❌ | ✅ |
| 执行能力 | ❌ | ✅ |
| 交互模式 | ❌ | ✅ |
| 责任闭环 | ❌ | ✅ |

**结束语**：
> "这就是我们 Agent 开发工程师的工作成果：让 AI 不仅会'说'，更会'做'！谢谢大家！"

---

## 🎯 演示要点

1. **节奏控制**：每个部分严格把控时间
2. **互动性**：适时提问"大家看这里..."
3. **可视化**：多展示代码和效果对比
4. **专业性**：强调技术亮点和创新点

## 📝 备用方案

- 如果现场网络不稳定：使用录屏视频
- 如果时间紧张：跳过步骤 1 和 2，直接从版本 3 开始
- 如果评委提问：准备好技术细节的解释
