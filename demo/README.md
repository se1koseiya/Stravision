# Agent 开发演示目录

本目录用于竞赛现场演示，包含：

## 📁 文件说明

- `prompt-skill.ts` - 提示词工程示例文件（现场编写）
- `data-injection.json` - 数据注入示例
- `demo-script.md` - 演示脚本和流程

## 🎯 用途

1. **现场编写提示词** - 展示如何设计和优化 AI 提示词
2. **数据注入演示** - 展示后端如何将实时数据注入到提示词中
3. **效果对比** - 对比注入数据前后的 AI 回复质量

## 💡 使用方式

在演示过程中，可以：
- 实时修改提示词文件
- 调整数据注入参数
- 观察 AI 助手的行为变化

---

**提示**：此目录下的文件仅用于演示，不影响生产环境代码。
