## 🔧 技术实现

### 1. Message 类型扩展
```typescript
interface Message {
  role: "user" | "assistant"
  content: string | Array<...>
  citations?: Citation[]
  reasoning?: { text: string; durationMs?: number }
  tasks?: TaskModel[]
  model?: string // 新增：保存使用的模型
}
```

### 2. 模型名称映射
```typescript
const getModelDisplayName = (model: string) => {
  const modelNames = {
    'auto': '智能模式',
    'qwen-plus': 'Qwen Plus',
    'qwen-max': 'Qwen Max',
    'qwen2.5-72b-instruct': 'Qwen2.5 72B',
    // ...
  }
  return modelNames[model] || model
}
```

### 3. 消息保存时包含模型
```typescript
const lastMsg = { 
  ...assistantMsg, 
  reasoning: { text: reasoningText, durationMs: Date.now() - startTs },
  model: selectedModel || aiSettings?.model // 保存模型信息
}
```
