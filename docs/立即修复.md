# 🚨 立即修复数据库问题

## 问题
```
数据库 "stravision" 不存在
```

## 解决方案（选择一个）

### 方法 1: pgAdmin（最简单）✨

1. 打开 **pgAdmin**（开始菜单搜索）
2. 连接到 PostgreSQL（输入密码）
3. 右键 **Databases** → **Create** → **Database...**
4. 名称输入：**stravision**
5. 点击 **Save**
6. 完成！运行 `npm run dev`

### 方法 2: SQL Shell

1. 打开 **SQL Shell (psql)**（开始菜单搜索）
2. 全部按回车，最后输入密码
3. 输入：`CREATE DATABASE stravision;`
4. 输入：`\q` 退出
5. 完成！运行 `npm run dev`

### 方法 3: 测试脚本

```bash

# 会告诉你具体问题
```
