# 台州方言语音识别支持

## 🎯 台州话支持详情

是的！我们的语音输入功能**完全支持浙江台州方言**！台州话作为吴语的重要分支，已经被专门配置在我们的语音识别系统中。

## 🗣️ 如何使用台州话

### 1. 选择台州方言
1. 点击语音输入区域的**语言选择器**
2. 在"中文方言"分组中选择**"吴语"**
3. 在子方言中选择**"台州话"**
4. 开始录音说台州话

### 2. 自动检测模式
- 选择"吴语 → 自动检测"
- 系统会自动识别您说的是台州话、上海话还是其他吴语方言
- 推荐台州用户使用此模式，识别准确率更高
