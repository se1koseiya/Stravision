# 搜索强制执行修复

## 问题描述

用户报告AI在处理搜索请求时（如"帮我查"、"帮我搜"、"我想知道"等），没有使用MCP工具进行真实的联网搜索，而是编造虚假的链接和信息。这是一个严重的问题，违背了AI助手的可信度原则。

## 问题分析

### 根本原因
1. **MCP工具指令不够强制**：原有的指令过于温和，AI可以选择性忽略
2. **搜索意图检测不完整**：关键词列表不够全面，遗漏了常见的搜索表达
3. **缺乏反编造机制**：没有明确禁止AI编造链接和信息
4. **工具调用优先级不明确**：AI不知道何时必须调用工具

### 具体表现
- AI收到"帮我抓取一下bilibili上关于草莓种植的视频连接"时
- 没有调用任何MCP搜索工具
- 直接编造了虚假的B站视频链接
- 提供了看似真实但完全虚构的信息

## 解决方案

### 1. 强化MCP工具指令

**修改文件**: `app/api/chat/route.ts`

**原有指令问题**:
```typescript
**重要规则：**
1. 当用户询问天气、搜索、路线规划等问题时，你**必须**主动调用对应的工具获取实时数据，而不是凭记忆回答。
```

**新的强化指令**:
```typescript
**🚨 严格执行规则：**
1. **严禁编造、虚构或猜测任何信息**！当用户询问需要搜索的内容时，你**必须**主动调用搜索工具获取真实数据。
2. **搜索类请求强制调用**：当用户说"帮我查"、"帮我搜"、"我想知道"、"找一下"、"搜索"等时，你**必须立即**调用相应的搜索工具，**绝对不能**凭记忆或编造答案。
3. **禁止编造链接**：严禁编造任何网址、链接或引用。所有链接必须来自真实的工具调用结果。

**⚠️ 特别警告：**
- 如果你没有调用工具就回答了需要搜索的问题，这是严重错误！
- 如果你编造了任何链接或信息，这是严重违规！
- 必须先调用工具获取真实数据，再基于结果回答用户。
```

### 3. 强制搜索指令

当检测到搜索意图时，注入强制指令：

```typescript
forcedToolPrompt = `
**🚨 强制搜索指令：**
用户的请求包含搜索意图："${lastUserContent}"

你**必须立即**调用搜索工具（如 \`${bestTool.function.name}\`）来获取真实信息。

**严禁行为：**
- ❌ 不能凭记忆回答
- ❌ 不能编造任何链接或信息
- ❌ 不能猜测或推测内容

**必须行为：**
- ✅ 立即调用 \`${bestTool.function.name}\` 工具
- ✅ 基于真实搜索结果回答
- ✅ 提供真实的链接和信息
`
```

### 4. 加强引用规则

在引用指令中添加反编造条款：

```typescript
"9. **🚨 严禁编造任何链接、网址或引用信息！所有链接必须来自真实的工具调用结果！**"
```

通过强化MCP工具指令、扩展搜索意图检测、增加强制搜索机制和加强反编造规则，成功解决了AI编造信息的问题。现在AI在收到搜索请求时会：

1. **强制调用MCP搜索工具**
2. **基于真实搜索结果回答**
3. **提供真实可验证的链接**
4. **不再编造任何虚假信息**

这大大提高了AI助手的可信度和实用性，确保用户获得真实、准确的信息。
