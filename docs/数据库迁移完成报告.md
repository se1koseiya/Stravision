## 🔧 主要技术变更

### SQL 语法变更

```sql
-- SQLite (旧)
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  ...
);
PRAGMA table_info(users);

-- PostgreSQL (新)
CREATE TABLE users (
  id BIGSERIAL PRIMARY KEY,
  ...
);
SELECT * FROM information_schema.columns WHERE table_name='users';
```

### 连接方式变更

```javascript
// SQLite (旧)
const db = new Database('./data/users.db');
const rows = db.prepare("SELECT * FROM users WHERE id = ?").all(1);

// PostgreSQL (新)
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
const result = await pool.query("SELECT * FROM users WHERE id = $1", [1]);
const rows = result.rows;
```

### 环境变量变更

```bash
# 旧配置
DATABASE_PATH=./data/users.db

# 新配置
DATABASE_URL=postgresql://postgres:password@localhost:5432/stravision
```

## 📋 使用指南

### 本地开发快速开始

```bash
# 1. 安装 PostgreSQL
brew install postgresql  # macOS
# 或从官网下载安装包

# 2. 创建数据库
psql -U postgres -c "CREATE DATABASE stravision;"

# 3. 配置环境变量（编辑 .env）
DATABASE_URL=postgresql://postgres:password@localhost:5432/stravision

# 4. 迁移数据（如果有 SQLite 数据）
node scripts/migrate-sqlite-to-postgres.js

# 5. 启动应用
npm run dev
```

### Docker 部署快速开始

```bash
# 1. 配置环境变量
cp .env.postgres.example .env
# 编辑 .env 文件

# 2. 启动服务
docker-compose up -d

# 3. 查看日志
docker-compose logs -f web
```

## ⚠️ 重要提示

### 1. 依赖包说明

项目中保留了 `better-sqlite3` 依赖，仅用于数据迁移脚本。如果不需要从 SQLite 迁移数据，可以移除：

```bash
npm uninstall better-sqlite3 @types/better-sqlite3 @prisma/adapter-better-sqlite3
```

### 2. 数据兼容性

为保持向后兼容：
- 时间戳使用 `BIGINT` 存储毫秒级时间戳
- 布尔值使用 `INTEGER` (0/1)
- JSON 字段使用 `TEXT` 存储

### 3. 备份建议

迁移前请务必备份：
- SQLite 数据库文件（如有）
- 环境变量配置文件
- 重要业务数据
