# AI 助手图片识别功能

## 功能说明

AI 助手支持上传图片并让 AI 分析图片内容。系统会自动选择支持视觉的模型（如 qwen-vl-plus）来处理图片。

## 使用方法

### 1. 上传图片

在 AI 助手聊天界面：
1. 点击输入框左侧的 📎 图片按钮
2. 选择要上传的图片文件
3. 图片会显示在输入框上方的预览区域

### 2. 发送消息

1. 输入你的问题（如："图片的草莓长得如何？"）
2. 点击发送按钮
3. AI 会分析图片并回答你的问题

## 支持的图片格式

- JPG/JPEG
- PNG
- GIF
- WebP
- BMP

## 图片大小限制

- 单张图片最大 10MB
- 建议图片尺寸不超过 4096x4096 像素

## 技术实现

### 消息格式

当包含图片时，消息内容采用 OpenAI 兼容的多模态格式：

```typescript
{
  role: "user",
  content: [
    { type: "text", text: "用户的问题" },
    { type: "image_url", image_url: { url: "data:image/jpeg;base64,..." } }
  ]
}
```

### 模型自动选择

系统会根据消息内容自动选择合适的模型：

- **有图片** → 自动使用 `qwen-vl-plus` 或 `qwen-vl-max`
- **无图片** → 使用用户选择的模型

### API 兼容性

- **DashScope 兼容模式**: 自动转换为 OpenAI 格式
- **DashScope 原生模式**: 自动转换为 DashScope 格式
  ```typescript
  { image: "data:image/jpeg;base64,..." }
  ```

## 常见问题

### Q: 为什么上传图片后没有反应？

**A**: 检查以下几点：
1. 图片文件大小是否超过 10MB
2. 图片格式是否支持
3. 浏览器控制台是否有错误信息

### Q: AI 无法识别图片内容？

**A**: 可能的原因：
1. 图片质量太低或模糊
2. 图片内容不清晰
3. 模型不支持该类型的图片分析

### Q: 可以同时上传多张图片吗？

**A**: 目前支持多张图片上传，但建议一次不超过 3 张以获得最佳效果。

### Q: 图片会被保存吗？

**A**: 
- 图片会被转换为 Base64 编码
- 存储在会话历史中
- 不会单独保存到服务器文件系统

## 使用示例

### 示例 1: 植物健康诊断

```
用户: [上传草莓植株图片]
用户: 这些草莓的叶子看起来怎么样？有什么问题吗？

AI: 从图片中可以看到，草莓植株整体生长良好，叶片呈现健康的绿色。
不过我注意到：
1. 部分叶片边缘有轻微的褐色斑点，可能是缺钙或病害的早期症状
2. 叶片密度较高，建议适当疏叶以改善通风
3. 果实发育正常，颜色鲜艳

建议：
- 补充钙肥
- 加强通风
- 定期检查病虫害
```

### 示例 2: 病虫害识别

```
用户: [上传叶片特写图片]
用户: 叶子上这些斑点是什么？

AI: 根据图片分析，叶片上的症状可能是：
1. 灰霉病（Botrytis cinerea）
   - 特征：灰褐色斑点，边缘不规则
   - 原因：湿度过高，通风不良
   
建议处理方案：
- 降低湿度至 60% 以下
- 增强通风
- 喷施杀菌剂
- 清除病叶
```

### 示例 3: 生长阶段判断

```
用户: [上传果实图片]
用户: 这些草莓什么时候可以采摘？

AI: 从图片来看：
- 果实颜色：约 70% 转红
- 成熟度：接近采摘期
- 建议：再等 2-3 天，当果实完全转红时采摘

最佳采摘时机：
- 果实 90% 以上转红
- 表面有光泽
- 果肉稍软但不过软
```

## 最佳实践

### 拍摄技巧

1. **光线充足**: 自然光或补光灯
2. **焦距清晰**: 确保主体清晰
3. **角度合适**: 正面或 45° 角拍摄
4. **背景简洁**: 避免杂乱背景干扰

### 提问技巧

1. **具体明确**: "叶子上的斑点是什么？" 而不是 "这是什么？"
2. **提供上下文**: "这是草莓植株，种植了 2 个月"
3. **多角度拍摄**: 提供整体和局部照片

### 性能优化

1. **压缩图片**: 上传前适当压缩可加快处理速度
2. **合理裁剪**: 只保留关键部分
3. **批量处理**: 相似问题可以一次上传多张图片

## 故障排查

### 图片上传失败

```
错误: Failed to upload image
```

**解决方案**:
1. 检查图片大小（< 10MB）
2. 检查图片格式
3. 检查网络连接
4. 清除浏览器缓存

### AI 无法识别

```
AI: 抱歉，我无法识别图片内容
```

**解决方案**:
1. 重新拍摄更清晰的图片
2. 调整光线和角度
3. 提供更多文字描述
4. 尝试不同的模型

### 响应缓慢

**解决方案**:
1. 压缩图片大小
2. 减少同时上传的图片数量
3. 检查网络速度
4. 等待服务器响应

## 技术细节

### 图片编码

```typescript
// 将图片文件转换为 Base64
const reader = new FileReader();
reader.onload = (e) => {
  const base64 = e.target?.result as string;
  // base64 格式: data:image/jpeg;base64,/9j/4AAQ...
};
reader.readAsDataURL(file);
```

### 消息构建

```typescript
const userMessageContent = attachments.length > 0
  ? [
      { type: "text", text: userMsg },
      ...attachments.map(url => ({ 
        type: "image_url", 
        image_url: { url } 
      }))
    ]
  : userMsg;
```

### 模型选择逻辑

```typescript
// 检测是否包含图片
const hasImageContent = messages.some(m => 
  Array.isArray(m.content) && 
  m.content.some(c => c.type === "image_url")
);

// 自动选择视觉模型
if (hasImageContent && !isVLMModel) {
  effectiveModel = 'qwen-vl-plus';
}
```
