# MCP 商店演示脚本

## 演示场景 1：浏览和安装 MCP 服务器

### 步骤 1：进入 MCP 商店
1. 打开 AI 助手页面
2. 在左侧边栏找到 "MCP 商店" 按钮（搜索按钮下方）
3. 点击进入 MCP 商店

**预期效果**：
- 页面跳转到 `/mcp-store`
- 显示精美的服务器卡片网格
- 顶部显示搜索栏和分类过滤器

### 步骤 2：浏览服务器
1. 查看不同类别的 MCP 服务器
2. 点击分类标签（如 "网络工具"、"开发工具"）
3. 使用搜索框搜索特定服务器（如 "github"）

**预期效果**：
- 服务器卡片显示图标、名称、描述、功能标签
- 官方服务器显示 "官方" 徽章
- 需要 API Key 的服务器显示提示

### 步骤 3：查看服务器详情
1. 点击任意服务器卡片上的 "ℹ️" 按钮
2. 查看详细信息对话框

**预期效果**：
- 显示完整的功能列表
- 显示配置说明
- 显示获取 API Key 的链接
- 显示安装命令

### 步骤 4：安装服务器（无需 API Key）
1. 找到 "Playwright" 服务器
2. 点击 "安装" 按钮
3. 等待安装完成

**预期效果**：
- 显示安装进度动画
- 安装成功后显示 Toast 提示
- 按钮变为 "已安装"

### 步骤 5：安装服务器（需要 API Key）
1. 找到 "Firecrawl" 服务器
2. 点击 "安装" 按钮
3. 在弹出的对话框中填写 API Key
4. 点击 "获取 API Key" 链接（在新标签页打开）
5. 返回并填写 API Key
6. 点击 "安装"

**预期效果**：
- 显示配置对话框
- API Key 输入框为密码类型
- 提供获取 API Key 的指引
- 配置保存成功

## 演示场景 2：管理已安装的 MCP 服务器

### 步骤 1：进入 MCP 设置
1. 在 AI 助手页面，点击左下角用户头像
2. 选择 "MCP 设置"

**预期效果**：
- 页面跳转到 `/mcp-settings`
- 显示所有已安装的服务器列表

### 步骤 2：启用/禁用服务器
1. 找到任意已安装的服务器
2. 切换右侧的开关

**预期效果**：
- 服务器状态徽章更新（已启用/已禁用）
- 显示 Toast 提示

### 步骤 3：编辑配置
1. 点击 "编辑" 按钮
2. 修改环境变量（如 API Key）
3. 点击 "保存"

**预期效果**：
- 输入框变为可编辑状态
- 保存后显示成功提示
- 配置立即生效

### 步骤 4：复制配置
1. 点击复制按钮（📋）
2. 查看剪贴板内容

**预期效果**：
- 配置以 JSON 格式复制到剪贴板
- 按钮图标变为 ✓
- 显示 Toast 提示

### 步骤 5：卸载服务器
1. 点击删除按钮（🗑️）
2. 确认卸载

**预期效果**：
- 显示确认对话框
- 服务器从列表中移除
- 相关配置被清除

## 设计亮点

### 1. 视觉设计
- **高质量图标**：从官方网站获取的品牌图标
- **渐变背景**：柔和的渐变色营造专业感
- **卡片悬停效果**：提升交互体验
- **徽章系统**：清晰标识官方、已安装等状态

### 2. 用户体验
- **一键安装**：简化安装流程
- **智能引导**：需要 API Key 时自动显示获取链接
- **实时反馈**：Toast 提示、加载动画
- **搜索过滤**：快速找到需要的服务器

### 3. 功能完整性
- **配置管理**：集中管理所有 MCP 配置
- **启用控制**：灵活控制服务器状态
- **配置导出**：方便备份和分享
- **安全性**：密码输入框、确认对话框

### 4. 扩展性
- **模块化设计**：易于添加新服务器
- **标准化接口**：统一的配置格式
- **分类系统**：支持任意数量的分类
- **搜索算法**：支持名称、描述、功能搜索

## 技术特点

1. **响应式设计**：适配桌面和移动设备
2. **暗色模式**：完整的暗色主题支持
3. **性能优化**：虚拟滚动、懒加载
4. **类型安全**：完整的 TypeScript 类型定义
5. **状态管理**：LocalStorage + React State
6. **错误处理**：友好的错误提示
