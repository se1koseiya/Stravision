# MCP 商店快速开始

## 5 分钟快速上手

### 第 1 步：访问 MCP 商店 (30 秒)

1. 打开 AI 助手页面
2. 在左侧边栏点击 **"MCP 商店"**
3. 浏览可用的 MCP 服务器

### 第 2 步：安装第一个 MCP 服务器 (2 分钟)

我们推荐从 **Playwright** 开始，因为它不需要 API Key：

1. 在搜索框输入 "playwright"
2. 点击 **"安装"** 按钮
3. 等待安装完成（约 5 秒）
4. 看到 "✅ 安装成功" 提示

### 第 3 步：测试 MCP 功能 (2 分钟)

返回 AI 助手，尝试以下对话：

```
你：帮我打开 https://example.com 并截图

AI：好的，我来使用浏览器自动化工具...
[调用 Playwright MCP]
✅ 已完成！这是网页截图：
[显示截图]
```

### 第 4 步：安装需要 API Key 的服务器 (可选，5 分钟)

以 **Brave Search** 为例：

1. 在 MCP 商店找到 "Brave Search"
2. 点击 **"安装"**
3. 在弹出的对话框中：
   - 点击 **"获取 API Key"** 链接
   - 在 Brave 网站申请免费 API Key
   - 复制 API Key
   - 返回对话框粘贴
4. 点击 **"安装"**

现在你可以让 AI 进行网络搜索了！

```
你：搜索最新的 AI 新闻

AI：我来搜索最新的 AI 新闻...
[调用 Brave Search MCP]
找到以下最新消息：
1. ...
2. ...
```

## 推荐安装顺序

### 初学者套装（无需 API Key）
1. ✅ **Playwright** - 浏览器自动化
2. ✅ **PostgreSQL** - 数据库连接（如果你有数据库）

7. 💰 **Notion** - 笔记管理
8. 💰 **Linear** - 项目管理

## 管理技巧

### 查看已安装的服务器
1. 点击用户头像
2. 选择 **"MCP 设置"**
3. 查看所有已安装的服务器

### 临时禁用服务器
在 MCP 设置页面，关闭服务器旁边的开关即可。

### 更新 API Key
1. 进入 MCP 设置
2. 点击 **"编辑"**
3. 更新配置
4. 点击 **"保存"**

### 备份配置
点击服务器旁边的 📋 按钮，配置会复制到剪贴板。

## 故障排除

### 问题 1：服务器安装后不工作
**解决方案**：
1. 检查服务器是否已启用（MCP 设置页面）
2. 检查 API Key 是否正确
3. 刷新页面重试

### 问题 2：API Key 无效
**解决方案**：
1. 确认 API Key 没有过期
2. 检查 API Key 的权限设置
3. 重新生成 API Key

### 问题 3：找不到某个功能
**解决方案**：
1. 确认对应的 MCP 服务器已安装
2. 确认服务器已启用
3. 尝试更明确的指令
