# 农业 MCP 服务器使用指南

## 🌾 概述

本指南专为农业智能平台设计，介绍如何使用 MCP 服务器增强农业管理和决策能力。

## 📦 农业相关 MCP 服务器

### 1. 天气服务

#### 彩云天气
- **功能**：实时天气、小时预报、周预报、历史数据、天气预警
- **适用场景**：灌溉决策、病虫害预警、农事安排
- **API 获取**：https://dashboard.caiyunapp.com/
- **特点**：
  - 分钟级降雨预报
  - 精确到街道的天气数据
  - 灾害性天气预警
  - 历史天气数据查询

**使用示例：**
```
你：查询未来3天的天气，判断是否适合喷洒农药
AI：[调用彩云天气 MCP]
根据天气预报：
- 今天：晴，温度25-32°C，风力2级，适合喷洒
- 明天：多云转阴，下午可能有小雨，不建议喷洒
- 后天：阴有中雨，不适合喷洒
建议：今天上午进行喷洒作业
```

#### 高德天气
- **功能**：实时天气、天气预报、空气质量、生活指数
- **适用场景**：日常天气查询、空气质量监测
- **API 获取**：https://console.amap.com/dev/key/app
- **特点**：
  - 覆盖全国3000+城市
  - 空气质量AQI指数
  - 生活指数（穿衣、洗车、运动等）
  - 免费额度充足

**使用示例：**
```
你：今天空气质量如何？适合进行田间作业吗？
AI：[调用高德天气 MCP]
当前空气质量：良（AQI 68）
PM2.5: 48 μg/m³
建议：空气质量良好，适合田间作业
```

#### 和风天气
- **功能**：实时、逐小时、逐天预报、灾害预警
- **适用场景**：精准天气预报、灾害预警
- **API 获取**：https://console.qweather.com/
- **特点**：
  - 全球天气数据
  - 168小时逐小时预报
  - 15天逐天预报
  - 台风路径、暴雨预警

**使用示例：**
```
你：未来一周有没有极端天气？需要做什么准备？
AI：[调用和风天气 MCP]
预警信息：
- 3天后（周五）有强对流天气预警
- 预计有大风和冰雹
建议准备：
1. 加固温室大棚
2. 提前收获成熟作物
3. 检查排水系统
```

### 2. 地图与路线

#### 高德路线规划
- **功能**：路线规划、地理编码、距离计算
- **适用场景**：农资配送、农机调度、田间巡查
- **API 获取**：https://console.amap.com/dev/key/app
- **特点**：
  - 多种出行方式（驾车、步行、骑行）
  - 实时路况
  - 距离和时间估算
  - 地址解析

**使用示例：**
```
你：规划从仓库到3号大棚的最优路线
AI：[调用高德路线规划 MCP]
路线规划：
- 距离：2.3公里
- 预计时间：5分钟
- 路线：仓库 → 东路 → 农场主路 → 3号大棚
- 建议：使用电动车，路况良好
```

### 3. 传感器与监测

#### 土壤传感器
- **功能**：土壤湿度、温度、pH值、NPK养分监测
- **适用场景**：精准灌溉、施肥决策、土壤管理
- **配置**：连接您的 IoT 平台
- **特点**：
  - 实时数据采集
  - 多参数监测
  - 历史数据分析
  - 异常报警

**使用示例：**
```
你：1号地块的土壤状况如何？需要灌溉吗？
AI：[调用土壤传感器 MCP]
1号地块土壤数据：
- 湿度：45%（适中）
- 温度：22°C
- pH值：6.8（适宜）
- 氮含量：偏低
建议：暂不需要灌溉，建议追施氮肥
```

### 4. 智能决策

#### 作物病害识别
- **功能**：病害识别、虫害诊断、防治建议
- **适用场景**：病虫害防治、作物健康管理
- **配置**：配置病害识别 API
- **特点**：
  - 图像识别
  - 病害诊断
  - 防治方案
  - 知识库查询

**使用示例：**
```
你：[上传作物叶片照片] 这是什么病害？如何防治？
AI：[调用作物病害识别 MCP]
识别结果：番茄晚疫病
严重程度：中度
防治建议：
1. 立即喷施甲霜灵锰锌
2. 清除病叶并销毁
3. 加强通风，降低湿度
4. 7天后复查
```

#### 灌溉控制系统
- **功能**：自动灌溉、计划调度、水量控制
- **适用场景**：智能灌溉、水资源管理
- **配置**：连接灌溉控制系统
- **特点**：
  - 自动化控制
  - 分区管理
  - 定时任务
  - 用水统计

**使用示例：**
```
你：根据天气预报和土壤湿度，制定本周灌溉计划
AI：[调用灌溉控制系统 MCP + 天气 MCP + 土壤传感器 MCP]
本周灌溉计划：
- 周一：1号地块，早6:00，30分钟
- 周三：2号地块，早6:00，45分钟
- 周五：3号地块，早6:00，30分钟
说明：周四有降雨，取消当天灌溉
```

#### 农场数据平台
- **功能**：数据整合、实时监控、历史分析、报表生成
- **适用场景**：综合数据管理、决策支持
- **配置**：连接农场数据平台
- **特点**：
  - 多源数据整合
  - 可视化展示
  - 趋势分析
  - 自动报表

**使用示例：**
```

本月运营报告：

- 平均土壤湿度：52%（适宜）
- 病虫害发生：3次（轻度）

```

## 🎯 典型应用场景

### 场景 1：智能灌溉决策

**需求**：根据天气、土壤状况自动制定灌溉计划

**使用的 MCP**：
- 彩云天气（天气预报）
- 土壤传感器（土壤湿度）
- 灌溉控制系统（执行灌溉）

**对话示例**：
```
你：分析未来3天天气和当前土壤状况，制定灌溉计划

AI：正在分析...
[调用彩云天气 MCP] 获取天气预报
[调用土壤传感器 MCP] 获取土壤数据

分析结果：
1. 天气情况：
   - 今明两天晴朗，蒸发量大
   - 第3天有中雨
   
2. 土壤状况：
   - 1号地块：湿度38%，需要灌溉
   - 2号地块：湿度55%，暂不需要
   - 3号地块：湿度42%，需要灌溉

3. 灌溉计划：
   [调用灌溉控制系统 MCP] 设置计划
   - 今天傍晚：1号地块灌溉40分钟
   - 明天早晨：3号地块灌溉35分钟
   - 第3天：取消所有灌溉（有降雨）

计划已自动设置，将按时执行。
```

### 场景 2：病虫害预警与防治

**需求**：根据天气条件预警病虫害风险

**使用的 MCP**：
- 和风天气（温湿度预报）
- 作物病害识别（病害知识库）
- 农场数据平台（历史数据）

**对话示例**：
```
你：分析本周病虫害风险

AI：正在分析...
[调用和风天气 MCP] 获取温湿度预报
[调用农场数据平台 MCP] 查询历史病害记录

风险评估：
1. 高风险期：周三至周五
   - 温度25-28°C，湿度80%以上
   - 适合真菌病害发生
   
2. 重点关注：
   - 番茄晚疫病（高风险）
   - 黄瓜霜霉病（中风险）
   
3. 预防措施：
   - 周二下午喷施保护性杀菌剂
   - 加强通风，降低棚内湿度
   - 每日巡查，发现病株及时处理
   
4. 巡查重点区域：
   - 2号大棚（历史高发区）
   - 5号大棚（通风较差）
```

### 场景 3：农资配送优化

**需求**：优化农资配送路线

**使用的 MCP**：
- 高德路线规划（路线优化）
- 农场数据平台（需求统计）

**对话示例**：
```
你：今天需要给3个大棚配送肥料，规划最优路线

AI：正在规划...
[调用农场数据平台 MCP] 获取大棚位置和需求
[调用高德路线规划 MCP] 计算最优路线

配送计划：
1. 配送清单：
   - 1号大棚：复合肥50kg
   - 4号大棚：有机肥100kg
   - 7号大棚：复合肥30kg
   
2. 最优路线：
   仓库 → 1号大棚(1.2km) → 4号大棚(0.8km) → 7号大棚(1.5km) → 仓库
   总距离：4.2km
   预计时间：25分钟
   
3. 装载建议：
   - 先装7号大棚货物（最后卸）
   - 再装4号大棚货物
   - 最后装1号大棚货物（最先卸）
```

**需求**：每日农事安排建议

**使用的 MCP**：

```
✅ 适宜进行：
1. 喷洒农药（上午8-10点，风力小）

⚠️ 注意事项：

2. 下午3点后可进行灌溉
3. 注意防晒，做好防护

📋 今日任务：
1. 【紧急】3号大棚番茄需要采收
2. 【计划】5号大棚育苗移栽
3. 【日常】巡查各大棚，记录生长情况
```

## 🔧 配置指南

### 1. 彩云天气配置

```bash
# 1. 注册彩云天气账号
访问：https://dashboard.caiyunapp.com/

# 2. 获取 API Token
登录后在控制台获取

# 3. 在 MCP 商店安装
搜索"彩云天气" → 点击安装 → 填入 Token

# 4. 测试
你：查询北京今天的天气
```

### 2. 高德地图配置

```bash
# 1. 注册高德开放平台账号
访问：https://lbs.amap.com/

# 2. 创建应用
控制台 → 应用管理 → 创建新应用 → 添加 Key

# 3. 选择服务
Web服务 → 天气查询、路线规划

# 4. 在 MCP 商店安装
搜索"高德天气"或"高德路线规划" → 安装 → 填入 Key
```

### 3. 和风天气配置

```bash
# 1. 注册和风天气账号
访问：https://www.qweather.com/

# 2. 创建项目
控制台 → 项目管理 → 创建项目 → 获取 Key

# 3. 选择版本
免费版：每天1000次请求
付费版：更多请求和功能

# 4. 在 MCP 商店安装
搜索"和风天气" → 安装 → 填入 Key
```

### 4. 自定义传感器配置

如果您有自己的 IoT 平台或传感器系统：

```bash
# 1. 在 MCP 商店点击"自定义"

# 2. 填写信息
名称：my-farm-sensors
显示名称：我的农场传感器
分类：农业
命令：npx
参数：-y @my-company/farm-sensor-mcp

# 3. 配置环境变量
IOT_ENDPOINT: https://your-iot-platform.com/api
IOT_API_KEY: your-api-key

# 4. 保存并安装
```

```

AI：
[天气] 今日晴，温度适宜
[土壤] 整体湿度偏低

1. 上午进行灌溉作业
2. 下午适合喷洒农药

```

设置自动化规则：

```
你：如果土壤湿度低于40%且未来3天无降雨，自动启动灌溉

AI：已设置自动化规则

- 土壤湿度 < 40%
- 未来3天无降雨
执行动作：
- 启动对应区域灌溉
- 发送通知
```
