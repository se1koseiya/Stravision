# 参考来源卡片重新设计 - 宝石绿主题

## 设计理念

全新的参考来源卡片采用宝石绿（Emerald）主题的渐变配色方案，与农业智慧平台的品牌色保持一致，提升视觉层次感和用户体验。

## 新设计特点

### 1. 渐变背景
- **主背景**：宝石绿到青绿色的柔和渐变
  - 浅色模式：`from-emerald-50/80 via-white to-teal-50/50`
  - 深色模式：`from-emerald-950/20 via-zinc-900 to-teal-950/20`

### 2. 顶部装饰条
- 绿色系渐变装饰条：`from-emerald-500 via-teal-500 to-cyan-500`
- 高度：1px
- 作用：增加视觉吸引力和品牌识别度

### 3. 网站图标容器
- 圆角方形设计（从圆形改为圆角矩形）
- 渐变背景：`from-emerald-100 to-teal-100`
- 边框：`border-emerald-200/50`
- 尺寸：6x6（从 5x5 增大）

### 4. 编号徽章
- 圆形渐变徽章
- 背景：`from-emerald-500 to-teal-600`
- 白色文字，粗体
- 阴影效果

### 5. 交互效果
- **悬停状态**：
  - 轻微上移：`hover:-translate-y-0.5`
  - 边框颜色变化：`hover:border-emerald-300`
  - 阴影增强：`hover:shadow-lg hover:shadow-emerald-100/50`
  - 链接文字间距增加：`hover:gap-2`

### 6. 底部操作区
- 渐变背景：`from-emerald-50/50 to-teal-50/50`
- 边框：`border-emerald-100/50`
- 按钮文字：宝石绿色，悬停时加深

## 触发按钮设计

### 新的触发按钮特点
- **渐变背景**：宝石绿到青绿色
- **编号徽章**：渐变圆形，白色文字
- **文字**：宝石绿色，加粗
- **悬停效果**：
  - 背景颜色加深
  - 阴影出现
  - 文字颜色变化

### 弹出面板设计
- **背景**：渐变背景 `from-emerald-50/30 to-white`
- **标题**：渐变文字效果 `from-emerald-600 to-teal-600`
- **边框**：柔和的宝石绿边框

## 配色方案

### 主色调
- **宝石绿系（Emerald）**：
  - 浅色：`emerald-50`, `emerald-100`, `emerald-200`
  - 中色：`emerald-500`, `emerald-600`, `emerald-700`
  - 深色：`emerald-900`, `emerald-950`

- **青绿色系（Teal）**：
  - 浅色：`teal-50`, `teal-100`
  - 中色：`teal-500`, `teal-600`
  - 深色：`teal-900`, `teal-950`

- **青色系（Cyan）**（装饰）：
  - `cyan-500`

### 品牌色对应
- **主色**：宝石绿 (#10B981) - 代表生机、成长、农业
- **辅助色**：青绿色 (#14B8A6) - 代表科技、智慧
- **点缀色**：青色 (#06B6D4) - 增加活力

### 对比度
- 确保文字在渐变背景上的可读性
- 深色模式下使用更深的渐变和更亮的文字

## 视觉层次

1. **顶部装饰条**：最醒目，绿色系渐变
2. **编号徽章**：次要焦点，渐变圆形
3. **标题**：主要内容，深色文字
4. **描述**：辅助信息，灰色文字
5. **底部操作**：行动号召，宝石绿链接

## 响应式设计

- 所有元素在不同屏幕尺寸下保持一致的视觉效果
- 文字使用 `line-clamp` 确保不会溢出
- 图标和徽章使用固定尺寸确保对齐

## 无障碍设计

- 保持足够的颜色对比度
- 使用语义化的 HTML 标签
- 支持键盘导航（`focus-visible:ring-2`）
- 提供清晰的悬停和焦点状态

## 动画效果

- **过渡时间**：300ms
- **缓动函数**：默认（ease）
- **变换**：
  - 垂直位移：`-translate-y-0.5`
  - 水平位移（图标）：`translate-x-0.5`
  - 间距变化：`gap-1.5` → `gap-2`

## 与旧设计的对比

### 旧设计
- ❌ 单调的灰白配色
- ❌ 简单的边框
- ❌ 缺乏视觉层次
- ❌ 交互反馈不明显
- ❌ 与品牌色不一致

### 新设计
- ✅ 现代化的宝石绿渐变配色
- ✅ 多层次的视觉效果
- ✅ 清晰的信息层级
- ✅ 丰富的交互反馈
- ✅ 品牌识别度高
- ✅ 与农业主题完美契合

## 性能优化

- 使用 CSS 渐变而非图片，减少资源加载
- 过渡动画使用 GPU 加速的属性（transform, opacity）
- 图标懒加载，失败时优雅降级
