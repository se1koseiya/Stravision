# MCP 快速使用指南

## 🎉 好消息！MCP 系统现在可以真正工作了！

之前 MCP 只有界面，现在已经完全集成到 AI 助手中，可以真正调用天气服务了。

## 📋 快速开始（3 步）

### 第 1 步：获取 API Key

选择一个天气服务并获取 API Key：

#### 选项 A：彩云天气（推荐）
1. 访问：https://dashboard.caiyunapp.com/
2. 注册账号
3. 创建应用
4. 复制 Token

#### 选项 B：高德天气
1. 访问：https://console.amap.com/
2. 注册账号
3. 创建应用（选择 Web 服务）
4. 复制 Key

#### 选项 C：和风天气
1. 访问：https://console.qweather.com/
2. 注册账号
3. 创建项目
4. 复制 Key

### 第 2 步：配置 MCP 服务

1. 打开 AI 助手页面
2. 点击输入框下方的 **"MCP 商店"** 按钮
3. 找到你选择的天气服务（如"彩云天气"）
4. 点击服务卡片
5. 在弹出的对话框中：
   - 粘贴你的 API Key
   - 点击 **"安装"** 按钮
6. 看到绿色勾选图标 ✓ 表示安装成功

### 第 3 步：开始使用

回到 AI 助手，直接问天气问题：

```
北京今天天气怎么样？
```

```
上海明天会下雨吗？
```

```
深圳这周的天气预报
```

## ✨ 功能特点

## 🔧 故障排除

### 问题 1：AI 说无法获取天气数据

**原因**：MCP 服务未配置或 API Key 无效

**解决**：
1. 检查 MCP 商店中服务是否已启用（绿色勾选）
2. 重新输入 API Key
3. 确认 API Key 有效且有配额

### 问题 2：返回的数据不准确

**原因**：城市识别错误

**解决**：
1. 使用完整的城市名称（如"北京"而不是"京"）
2. 避免使用简称或别名
3. 如果是小城市，尝试使用所在省份的省会城市

### 问题 3：MCP 状态指示器显示 0

**原因**：没有启用任何 MCP 服务

**解决**：
1. 访问 MCP 商店
2. 至少安装一个天气服务
3. 确保服务已启用

### 问题 4：API 配额用完

**原因**：免费 API 有调用次数限制

**解决**：
1. 等待配额重置（通常每天重置）
2. 升级到付费套餐
3. 或者配置另一个天气服务作为备选
