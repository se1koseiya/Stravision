# Dashboard 布局系统设计

## 概述
重新设计了dashboard的布局系统，引入了三种组件尺寸（小、中、大），并创建了多种预设布局组合，提供更灵活和美观的数据展示方式。

## 组件尺寸规格

### 小尺寸 (Small) - 2x2
- **网格尺寸**: 2列 × 2行
- **形状**: 正方形
- **适用场景**: 简单数据指标显示
- **特点**: 
  - 紧凑的信息展示
  - 适合快速浏览
  - 最小化的UI元素
  - 主要显示数值和状态

### 中等尺寸 (Medium) - 4x2  
- **网格尺寸**: 4列 × 2行
- **形状**: 横向长方形
- **适用场景**: 详细数据展示
- **特点**:
  - 平衡的信息密度
  - 包含趋势和详细信息
  - 适中的视觉层次
  - 支持更多交互元素

### 大尺寸 (Large) - 4x4
- **网格尺寸**: 4列 × 4行  
- **形状**: 正方形
- **适用场景**: 复杂数据分析和可视化
- **特点**:
  - 丰富的信息展示
  - 支持图表和复杂交互
  - 突出重要数据
  - 完整的功能体验

## 组件尺寸分配

### 高优先级组件 (大尺寸)
- **AI智能洞察**: 复杂的AI分析结果展示
- **光谱分析**: 详细的光谱数据可视化

### 中优先级组件 (中等尺寸)
- **温度监测**: 包含趋势和历史数据
- **湿度监测**: 详细的湿度信息和状态
- **天气状况**: 综合天气信息展示
- **土壤监测**: 土壤湿度和肥力双重显示
- **会员信息**: 用户状态和权限信息

### 低优先级组件 (小尺寸)
- **光照强度**: 简单的光照数值
- **CO₂浓度**: 空气质量指标
- **土壤肥力**: 综合肥力指数
- **氮含量**: NPK营养元素
- **磷含量**: NPK营养元素  
- **钾含量**: NPK营养元素

## 预设布局方案

### 1. 默认视图 (Default)
- **设计理念**: 平衡显示所有重要数据
- **特点**: AI洞察居左上角，环境数据居中，营养元素排列在底部
- **适用场景**: 日常监控和全面数据查看

### 2. 紧凑视图 (Compact)  
- **设计理念**: 最大化信息密度
- **特点**: 小组件密集排列，大组件放在下方
- **适用场景**: 小屏幕设备或需要查看更多数据

### 3. 数据优先 (Data First)
- **设计理念**: 突出显示关键数据分析
- **特点**: AI洞察和光谱分析占据上方主要位置
- **适用场景**: 数据分析和决策制定

### 4. 监控大屏 (Monitor)
- **设计理念**: 适合大屏幕监控显示  
- **特点**: 中等组件为主，便于远距离观看
- **适用场景**: 控制室大屏监控

### 5. 环境监测 (Environment)
- **设计理念**: 专注环境参数监控
- **特点**: 温湿度、光照、CO₂等环境数据优先显示
- **适用场景**: 环境控制和调节

### 6. 土壤监测 (Soil)
- **设计理念**: 专注土壤健康分析
- **特点**: 土壤相关数据集中在顶部显示
- **适用场景**: 土壤管理和施肥决策

## 技术实现

### 布局配置文件
```typescript
// lib/dashboard-layouts.ts
export const WIDGET_DIMENSIONS = {
  small: { w: 2, h: 2 },   // 小：正方形
  medium: { w: 4, h: 2 },  // 中：横向长方形  
  large: { w: 4, h: 4 }    // 大：正方形
}
```

### 组件尺寸支持
每个组件都支持 `size` 属性：
```typescript
interface WidgetProps {
  size?: 'small' | 'medium' | 'large'
  // ... 其他属性
}
```

### 响应式样式
组件根据尺寸自动调整：
- 字体大小
- 图标尺寸  
- 内边距
- 信息密度
- 交互元素

## 布局切换功能

### 预设切换
用户可以通过下拉菜单快速切换预设布局：
- 默认视图
- 紧凑视图  
- 数据优先
- 监控大屏
- 环境监测
- 土壤监测

### 自定义编辑
- 拖拽调整组件位置
- 调整组件大小
- 保存个性化布局
- 重置为预设布局

## 设计原则

### 信息层次
1. **主要信息**: 大尺寸组件，突出显示
2. **重要信息**: 中等尺寸组件，平衡展示  
3. **辅助信息**: 小尺寸组件，紧凑显示

### 视觉平衡
- 大组件作为视觉锚点
- 中等组件提供信息支撑
- 小组件填充细节信息

### 用户体验
- 快速信息获取
- 直观的数据对比
- 流畅的交互体验
- 个性化定制能力

## 扩展性

### 新组件添加
1. 定义组件尺寸和优先级
2. 添加到 `WIDGET_CONFIGS` 配置
3. 更新布局预设
4. 实现组件的尺寸适配

### 新布局预设
1. 分析使用场景需求
2. 设计组件排列方案
3. 添加到 `LAYOUT_PRESETS`
4. 更新UI选择器

### 自适应布局
系统支持根据可用组件和容器宽度自动生成布局：
```typescript
generateAdaptiveLayout(availableWidgets, containerWidth)
```

## 性能优化

### 布局缓存
- 预设布局静态配置
- 用户自定义布局本地存储
- 组件尺寸计算缓存

### 渲染优化  
- 组件按需渲染
- 尺寸变化平滑过渡
- 避免不必要的重新计算

## 总结

新的布局系统通过三种尺寸规格和六种预设布局，为用户提供了灵活而美观的数据展示方式。系统既保证了信息的有效传达，又提供了良好的用户体验和个性化定制能力。
