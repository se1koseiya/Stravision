# 🎤 台州话语音输入使用指南

## 📋 使用前准备

### 1. 用户登录
**重要**: 语音输入功能需要用户登录后才能使用。

如果看到"请先登录后再使用语音输入功能"的错误提示，请：
1. 点击页面右上角的登录按钮
2. 使用您的账号密码登录
3. 登录成功后即可使用语音输入功能

### 2. 浏览器权限
- 确保浏览器允许麦克风权限
- 推荐使用Chrome、Edge等现代浏览器
- 生产环境需要HTTPS协议

### 3. 环境要求
- 安静的录音环境
- 正常工作的麦克风设备
- 稳定的网络连接

## 🎯 台州话语音输入步骤

### 步骤1: 选择方言
1. 在AI助手页面找到语音输入区域
2. 点击语言选择器（显示当前语言的按钮）
3. 选择"中文方言" → "吴语" → "台州话"
4. 或者选择"吴语" → "自动检测"（推荐）

### 步骤2: 开始录音
1. 点击麦克风按钮开始录音
2. 看到红色脉冲动画表示正在录音
3. 用台州话清晰地说出您想要输入的内容
4. 再次点击按钮停止录音

### 步骤3: 查看结果
1. 系统会显示"识别中..."的状态
2. 识别完成后会显示转录结果
3. 结果会自动填入输入框
4. 您可以编辑转录结果后发送

## 🗣️ 台州话使用技巧

### 发音建议
- **语速适中**: 不要说得太快或太慢
- **发音清晰**: 尽量发音清晰，避免含糊不清
- **标准台州话**: 使用相对标准的台州话，避免过于生僻的方言词汇

### 内容建议
- **日常用语**: "侬好"、"吃饭了伐"、"蛮好个"
- **农业词汇**: "种田"、"草莓"、"浇水"、"施肥"
- **设备控制**: "帮我开一下浇水个机器"
- **天气查询**: "今朝天气哪能样？"

### 混合使用
- 可以在同一段话中混合使用台州话和普通话
- 专业术语建议用普通话表达
- 数字和日期建议用普通话

## ❌ 常见错误及解决方案

### "请先登录后再使用语音输入功能"
- **原因**: 用户未登录
- **解决**: 点击登录按钮，使用账号密码登录

### "麦克风权限被拒绝"
- **原因**: 浏览器未授权麦克风权限
- **解决**: 点击地址栏左侧锁图标，允许麦克风权限

### "语音识别请求失败"
- **原因**: 网络问题或API配额不足
- **解决**: 检查网络连接，联系管理员检查API配额

### "识别结果不准确"
- **原因**: 发音不清晰或环境噪音
- **解决**: 在安静环境下重新录音，注意发音清晰度

## 🔧 高级功能

### 方言自动检测
选择"吴语 → 自动检测"模式，系统会自动识别您说的是：
- 台州话
- 上海话
- 宁波话
- 温州话
- 其他吴语方言

### 置信度显示
系统会显示识别结果的置信度百分比，帮助您判断识别准确性。

### 检测语言显示
系统会显示检测到的语言和方言，确认识别是否正确。

## 📱 移动端使用

移动端的使用方法与桌面端相同：

2. 选择台州话方言
3. 点击麦克风按钮录音
4. 查看识别结果
